# Catálogo Galn Vstore

Imágenes públicas del catálogo de productos de [Galn Vstore](https://wa.me/56934553275) (Iquique, Chile), usadas como `image_link` del feed de Meta Commerce Manager / WhatsApp Business.

- 500 imágenes cuadradas (1080×1080, JPG)
- Feed: [`meta_feed.csv`](./meta_feed.csv)
- URLs: `https://raw.githubusercontent.com/emaase7/galnvstore-catalogo/main/images/<archivo>.jpg`

Este repositorio solo aloja archivos estáticos del catálogo. No es un proyecto de software.
